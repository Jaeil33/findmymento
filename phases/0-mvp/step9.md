## 작업

### 1. 공개 목록 — `src/app/(student)/qna/page.tsx`

- 분야 필터(5개), 최신순.
- 인증 없이 누구나 **읽을 수 있다.**
- 질문 카드: 가명 라벨, 학년, 분야, 질문 요약, 답변 수.

### 2. 질문 상세 스레드

하나의 질문과 그에 달린 답변들. 전부 공개.

**학생 표시는 가명 라벨만** — `중2 학생 A` 형식. 가명코드 원문을 화면에 절대 노출하지 마라(UI_GUIDE 안전 규칙 2). 라벨은 질문 단위로 안정적으로 생성한다(같은 질문을 다시 열면 같은 라벨).

### 3. 질문 작성

**작성에는 학생 가명코드가 필요하다. 익명은 읽기만 가능하다.**

이유: 공개 게시물이라 스팸·부적절 질문의 비용이 크고, 모더레이션 책임 주체가 기관이므로 기관이 추적할 수 있어야 한다. 읽기는 열어두고 쓰기만 막는다.

- 입력란 **바로 위에** 명시한다: "이 질문은 모두에게 공개되고, 선생님도 볼 수 있어요." 작은 회색 각주로 숨기지 마라(UI_GUIDE 안전 규칙 3).
- 제출 시 `isClean()` 검사. 걸리면 저장하지 않고 "연락처나 외부 링크는 쓸 수 없어요" 수준으로 안내한다. **어떤 규칙에 걸렸는지 상세히 알려주지 마라** — 우회 설명서가 된다.

### 4. 강사 답변

- 승인된(`approved`) 강사만 답변할 수 있다.
- 자기 답변만 수정·삭제할 수 있다. 타인 답변에 쓰기 권한이 없어야 한다.
- 답변에도 같은 `isClean()` 검사를 적용한다. 강사가 "제 번호로 연락주세요"를 쓰는 경로를 막는 게 핵심이다.

### 5. 기관 모더레이션

기관 담당자는 자기 기관 학생이 올린 질문을 **숨김 처리**할 수 있다. 숨김 처리된 질문은 anon 조회에서 보이지 않는다.

신고 기록은 `moderation_reports`에 남긴다.

### 6. 테스트 (TDD — 먼저 작성)

1. 인증 없이 목록·상세가 200으로 열린다
2. 가명코드 없이 질문 작성 시도 → 거부
3. 전화번호가 포함된 질문 → 저장되지 않고 안내 응답
4. 한국어 우회 표기(`공일공…`)가 포함된 질문 → 저장되지 않음
5. 미승인 강사의 답변 시도 → 거부
6. 강사 A가 강사 B의 답변 수정 시도 → 거부
7. 연락처가 포함된 강사 답변 → 저장되지 않음
8. 숨김 처리된 질문이 anon 조회에서 0건
9. 화면에 가명코드 원문이 렌더되지 않는다 (라벨만)
10. 같은 질문을 두 번 조회했을 때 가명 라벨이 동일하다

## 금지사항

- 1:1 메시지·DM·비공개 스레드를 만들지 마라. 이유: ADR-006의 영구 결정. 비공개 채널이 하나라도 생기면 "기관의 안전한 관리 체계 안의 연결"이라는 제품의 전제가 무너지고, 학교·기관 도입 논리도 같이 무너진다.
- 실시간 채팅·웹소켓·푸시 알림·짧은 주기 폴링을 넣지 마라. 이유: 비동기 전용으로 확정됐다. "밤 11시에 학생이 성인 강사와 실시간 대화" 시나리오를 구조적으로 차단한다.
- 학생 가명코드 원문을 화면·URL·DOM 속성에 넣지 마라. 이유: 코드가 노출되면 다른 학생이 그 코드로 응답 이력을 볼 수 있다.
- 차단 규칙을 상세히 안내하지 마라. 이유: 우회 방법 설명서가 된다.
- 답변에 모더레이션 검사를 생략하지 마라. 이유: 강사가 자기 연락처를 남겨 플랫폼 밖으로 빼내는 경로가 열린다. 안전 문제이자 수익 보호 문제다.
- 익명 사용자에게 작성 권한을 주지 마라. 이유: 모더레이션 책임 주체가 기관인데, 추적 불가능한 글은 기관이 책임질 수 없다.
- 기존 테스트를 깨뜨리지 마라.
